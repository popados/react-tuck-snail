Tuck the Snail · design system · palette review

Palette changes for light and dark

Extracted from the design system's tokens.json (21 color tokens, two themes), checked for contrast, then tuned. Tuck's art colors stay put. The changes fix three weak spots in dark mode and add the colors a mood tracker still lacks: a mood scale for insights, gentle notices with no red, and a terminal color set.

What the system has today

Each swatch shows light on the left and dark on the right. A single block means the color is the same in both themes.

Six changes, in priority order

1. Give dark-mode links a color of their own

link · new caramel-text

Dark link (#a9c9a0) and ink-muted (#b9ccb2) are 1.07:1 apart, so links only differ by the underline. Add a caramel-text token, Tuck's shell as a readable text color, and point link at it in both themes. Links become "the shell color" everywhere.

2. Make dark muted text actually muted

ink-muted · dark only

In dark mode ink is 14.3:1 and ink-muted is 10:1, so captions and body text look nearly the same. Drop dark ink-muted to #9fb39a. It still passes AA comfortably and restores the hierarchy. Keep term-dim as is; the terminal reads differently.

3. Make the selected mood chip easy to see

caramel-wash · both themes

The selected wash is only 1.26:1 (light) and 1.37:1 (dark) against an unselected chip, so the choice is easy to miss. Deepen the wash a step and give the selected chip a 3px outline, so the state never rests on fill alone.

4. Dim the art plate in dark mode

art-ground · dark only

Tuck's art sits on a #eef0ea plate in dark mode, a near-white rectangle that glows inside dark cards, which is a lot at 1:40am. #d9dfd4 keeps the fixed dark outlines at 10.9:1 and sits calmer on the page.

5. Add a mood scale for insights

5 new tokens · same in both themes

Insights charts have no colors yet. These five come from Tuck's own palette, step down in lightness from good to low so they read in grayscale and for color-blind users, and never use red. "Low" is a calm slate blue. Bars carry the brand's ink outline, so pastel fills still separate from the ground, and labels always pair with the ASCII face.

Tired (#7a9fbf) and shell day (#d69a6a) are close in lightness; they stay apart by hue (blue vs orange) and by their faces, @_-- and (@).

6. Add gentle notices, and map the terminal's colors

3 notice pairs · 16 ANSI slots

Saved, synced and "back up your data" messages need a home that is not red. Three washes with ink text cover them: moss-wash for done, butter-wash for needs a look, tear-wash for information. In tuckshell, the ANSI red slot becomes blush, so any tool that prints "error red" still looks like Tuck.

Full proposed palette

TokenLightDarkChange

Contrast is WCAG 2 ratio, measured against canvas and surface in each theme. Every text pairing is 4.5:1 or better. The full set is saved as design-palettes/proposed-tokens.json in the project files, ready to apply to the design system.

What stays the same

Caramel, moss, blush, butter and tear, the terminal ground, canvas and surface in both themes, and the "borders, not shadows" rule. The palette is still warm and calm, with no pastel purple and no red failure state on any surface.
